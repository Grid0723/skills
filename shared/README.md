# shared

全局共享 primitive——被 Grid 和 Fabric 两条脊椎引用，所有项目通用。

- **[writing-great-skills](./writing-great-skills/SKILL.md)** — 编写 Skill 的元规范：**从随机系统中拧出确定性**——四轴领域模型（调用/信息层级/引导/裁剪）+ 本体系专属约定。含种子模板和检查清单。公开参考在 `GLOSSARY.md`。
- **[grilling](./grilling/SKILL.md)** — 一对一接力式面试：**每次一个问题，把模糊想法具体化**。能探索不提问。产出是共识，不需要文件。被 Grid 拷问阶段和 Fabric 分类阶段引用。
- **[tdd](./tdd/SKILL.md)** — 红绿循环测试标准：**接缝驱动——先写失败测试、最小实现、重构清理**。含反模式定义。项目专属测试规范通过 `AGENTS.md` 的 `skills` 声明加载。
- **[doc-architecture](./doc-architecture/SKILL.md)** — 项目文档的**标准 8 目录骨架**——每目录撰写规范、Grid 阶段产出映射、项目初始化时自动生成 docs/ 结构。含 10 个空白模板文件。
