### 特殊约束与默认值

> 来源：`tqcenter.py` 源码分析补充。

| 约束项 | 说明 |
|:---|:---|
| `get_stock_list()` 的 `market` 默认值 | `'5'`（所有 A 股） |
| `get_stock_list()` 的 `market` 参数类型 | `str`（如 `'5'`、`'50'`），非 `int` |
| `subscribe_hq()` 最大订阅数 | **100** 只股票，超限回退并抛 ValueError |
| `refresh_kline()` 支持的周期 | 仅 `1m` / `5m` / `1d`（比 `get_market_data` 更受限） |
| `subscribe_quote()` 功能状态 | 源码标注 **"暂无实际功能"** |
| `get_divid_factors()` 时间参数 | 后端返回**全部**权息数据，`start_time`/`end_time` 仅用于客户端切片 |
| count 最大值 | 24000 条（`get_market_data`、公式批量调用等） |
| `formula_set_data_info()` count 特殊值 | `-1`=全部数据, `-2`=无序列数据, `0`=使用 start/end 时间 |

### convert_or_validate 代码格式转换

> 来源：`tqcenter.py` 源码 `convert_or_validate()` 函数。

```python
# 输入: List[str] → 输出: "市场#代码|市场#代码" 格式字符串
convert_or_validate(['600519.SH', '000001.SZ'])
# → '1#600519|0#000001'

# 输入: str → 验证格式并返回原字符串（验证失败返回空）
convert_or_validate('1#600519|0#000001')
# → '1#600519|0#000001'
```
