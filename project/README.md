# project

项目管理原子技能组——挂靠 Fabric 编排器，独立于知识管理阶段管道。用户调用。

- **[project-lifecycle](./project-lifecycle/SKILL.md)** — 项目生命周期：**立项（总览 + 外部链接）→ 按功能模块拆任务 → 归档前知识反哺**。阶段流转：启动→进行中→暂停→收尾→完成→归档。
- **[project-maintain](./project-maintain/SKILL.md)** — 项目维护：**里程碑回顾（CHANGELOG/commit log →「📝 里程碑总结」）+ 外部链接维护**（`file:///` 与 URL）。
