# map

领域地图的建立与更新（Global 阶段）。产出：概念网络 + 深挖队列。

## Leading Words

| 术语 | 定义 |
|------|------|
| **概念清单** | 单纯罗列的概念/术语——不是概念网络 |
| **概念网络** | 概念 + 语义关系（concept + relationship）形成的命题结构 |
| **粗粒度** | 阶段一建图：高覆盖、低精度、浅深度，目标是"知道有什么" |
| **语义关系** | 概念间关系的类型标签（十类：层级/组成/依赖/因果/功能/对比/替代/实现/约束/演化） |

## 步骤

### 1. 采集读物

- 搜索领域书籍/文章/视频/论文/文档，不求精只求全
- 用 defuddle/WebFetch 提取正文
- 完成标准：读物清单已建立，正文可访问

### 2. 提取概念

- 通读并抽出高频术语/专有名词，形成概念清单
- 完成标准：概念清单已产出

### 3. 聚合分类

- 合并去重、按主题分组，形成概念分类
- 完成标准：概念已去重并按主题分组

### 4. 建图

- 为概念间关系标注语义关系类型，生成 mermaid 领域地图
- 完成标准：领域地图已生成，每条连线有语义关系类型

### 5. 聚焦

- 区分核心概念与未知概念，按重要度排序，输出深挖队列
- 完成标准：深挖队列已产出，可进入 dig

## 参考

| 规则 | 说明 |
|------|------|
| 概念网络≠关键词合集 | 链路：概念清单 → 概念分类 → 概念关系 → 概念网络 |
| 覆盖率优先 | 阶段一追求高覆盖，不纠结单点精度 |

## 边界条件

- 地图已收敛（无新未知节点）→ 提示进入 harvest
