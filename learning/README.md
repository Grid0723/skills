# learning

Learn 脊椎内核——陌生领域学习策略的原子步骤（采集→建图→深挖→验证→收获→交接）。

## 用户调用

`learn` 编排器有状态、驱动多个原子 skill、涉及人类判断；原子 skill 由编排器路由或按需直接触发。

- **[learn](./learn/SKILL.md)** — **总编排器——陌生领域学习：建图→深挖→验证→更新地图→收获，交接 Fabric**。路由判断阶段、驱动 learning 原子 skill、管理 Global→Local→Global 循环。
- **[map](./map/SKILL.md)** — 建图（Global）：**采集→提取→聚合→标注语义关系生成领域地图→聚焦输出深挖队列**。建立/更新全局模型。
- **[dig](./dig/SKILL.md)** — 深挖（Local）：**按队列逐个概念定向搜集学习，形成关系命题**。追问五问（是什么/为什么存在/解决什么问题/依赖什么/与什么比较）。
- **[verify](./verify/SKILL.md)** — 验证（质量控制）：**交叉核查纠错——权威来源/冲突检测/事实观点区分/定义一致性/证据检查/过度概括检查**。不通过打回 dig 重挖。
- **[harvest](./harvest/SKILL.md)** — 收获（交接）：**把领域地图与概念理解转为可沉淀笔记，写入 `00_收集箱` 交接 Fabric**。产出 `状态: 待整理`。
