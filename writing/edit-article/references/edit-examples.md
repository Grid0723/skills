# DAG 编辑——完整示例

## 案例：5 段文章 → 依赖图 → 编辑顺序

### 原始文章结构

```
## 1 什么是布林带
概念定义——不依赖其他段落

## 2 布林带宽度压缩
依赖 §1 中的"布林带"定义

## 3 如何判断突破方向
依赖 §2 中的"宽度压缩=即将突破" + §1 的"布林带结构"

## 4 实战中的双向条件单
依赖 §3 的"突破方向判断" + §2 的"压缩信号"

## 5 常见错误
依赖 §1-4 的全部概念
```

### DAG 依赖图

```
§1 → ┬─ §2 → ┬─ §3 → §4
      │        │
      └────────┤
               └─ §5
```

### 编辑顺序

```
第 1 轮: §1（零依赖）
第 2 轮: §2（仅依赖 §1，§1 已在第 1 轮锁定）
第 3 轮: §3（依赖 §1+§2，均锁定）
第 4 轮: §4（依赖 §1-3，均锁定）
第 5 轮: §5（依赖全部，最后编辑）
```

### 反例：如果先编辑 §3

```
编辑 §3 → 重写了"突破方向判断"的逻辑
  ↓
§4 引用了旧版本的 §3 → §4 需要重新编辑
§5 引用了旧版本的 §3 → §5 也需要重新编辑
  ↓
级联重写：1 次编辑 → 3 次重写（§3, §4, §5）
```

**DAG 顺序的本质：先锁定"上游"，让下游编辑时引用的是定稿。**

## 常见编辑错误

| 错误 | 后果 | 防止 |
|------|------|------|
| 跳过依赖图直接从上到下编辑 | 第 3 段改了概念 X，第 7 段还引用旧版 X | 先建图，再编辑 |
| 编辑时引入新概念 | 新概念无 Grounding → 读者跳读 | 新概念只作为"引出"（引出后面段的主题），不被编辑的段自己使用 |
| 删除了一段但不更新依赖图 | 其他段引用被删段的锚点断裂 | 删除后检查所有 `fromSection` 引用 |
