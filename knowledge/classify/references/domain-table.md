# 分类判定示例

## 9 领域快速查表

| 领域目录 | 判据 | 典型内容 |
|---------|------|---------|
| `交易投资` | 涉及金融市场、量化策略、K 线、交易心理 | 量化分析、策略回测、投资理念 |
| `编程技术` | 涉及编程语言、框架、算法、架构 | Python、Node.js、TypeScript、SQL |

## 分类决策流程

```
笔记内容 → 主要话题是什么？
  ├── 单一领域 → 直接归入对应领域目录
  ├── 跨领域   → 找"主体"领域放文件夹，补跨领域标签桥接
  │               例: Python 量化笔记 → 放 交易投资/（主体领域）
  │                                   → tags 加 技术/python
  ├── 服务项目 → 归入 20_项目/<项目名>/
  └── 不确定   → 00_收集箱/待归类/（标记等待人工判断）
```

## 标签桥接示例

| 笔记主题 | 物理位置 | 标签 |
|---------|---------|------|
| 用 Python 做 ETF 回测 | `10_领域/交易投资/` | `交易/量化`, `技术/python` |
| NAS 上用 Docker 部署 Prisma | `10_领域/家庭网络与服务器/` | `家庭网络/NAS`, `技术/Docker` |
| Obsidian 中写交易日志 | `10_领域/工具与效率/` | `工具/Obsidian`, `交易/日志` |
