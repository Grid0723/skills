# learn

陌生领域学习总编排器。接收学习意图 → 路由判断阶段 → 驱动 learning 原子 skill → 完成后交接 Fabric。方法论见 Vault `docs/领域地图式学习.md`，设计见 `Grid/docs/Learn编排器设计.md`。

## Leading Words

| 术语 | 定义 |
|------|------|
| **领域地图** | 概念+语义关系构成的领域知识网络（概念清单→分类→关系→网络） |
| **Global → Local → Global** | 核心学习算法：建立/维护全局地图 → 局部深挖 → 新知识整合回地图，循环至收敛 |
| **粗粒度建图** | 阶段一：高覆盖、低精度、浅深度——知道"有什么"而非"是什么" |
| **语义关系** | 十类：层级/组成/依赖/因果/功能/对比/替代/实现/约束/演化 |
| **交接点** | Learn 产出写入 `00_收集箱`、`状态: 待整理`，由 Fabric 正常接续 |

## 阶段序列

```
建图(map) → 深挖(dig) → 验证(verify) → 更新地图(map) → 收获(harvest) → 交接 Fabric
```

## 步骤

### 1. 接收学习意图

- 确定陌生领域名与学习目标
- 意图模糊（领域名或目标不明确，如"想学点金融的东西"）→ 加载 `grilling` 一问一答具体化：领域名、学习深度（入门概览/系统掌握/精通）、范围边界（全领域/子主题）
- 完成标准：领域名与学习目标已明确

### 2. 建图——引用 map

加载 `map` skill。采集读物 → 提取概念 → 聚合关键词 → 标注语义关系生成领域地图 → 聚焦输出深挖队列。

- 完成标准：领域地图与深挖队列已产出

### 3. 深挖——引用 dig

加载 `dig` skill。按队列逐个概念搜集学习，形成关系命题。

- 完成标准：当前概念已形成单点理解

### 4. 验证——引用 verify

加载 `verify` skill。交叉核查纠错；不通过 → 打回 dig 重挖。

- 完成标准：结论通过验证或已打回重挖

### 5. 更新地图——引用 map（循环）

把已验证的新理解合并回地图，发现新空白则回到步骤 3；地图收敛则进入收获。

- 完成标准：地图已更新，且不再产生新未知节点（收敛）或用户决定停止

### 6. 收获——引用 harvest

加载 `harvest` skill。把地图与理解转为笔记写入 `00_收集箱`，交接 Fabric。

- 完成标准：产出笔记已写入收集箱并告知用户由 Fabric 接续

## 参考

| 规则 | 说明 |
|------|------|
| 验证是工程机制 | 验证是 Agent 学习流程的可靠性保障（认识论纠错），非 Novak 理论第五机制 |
| 漂亮≠正确 | AI+多篇文章可能汇聚出"看起来非常漂亮但错误"的地图，验证不可省略 |
| 不破坏现有管道 | 学习产出统一进收集箱，由 Fabric 正常接续（分类→归位→提炼→织网） |

## 边界条件

- 意图模糊（领域名/目标不明确）→ 先 `grilling` 具体化，再进入建图
- 学习途中发现值得剪藏的资料 → 提示走 fabric `capture` 顺手保存，不阻塞学习流程
- 用户只想学单个概念 → 直接 `dig`，跳过建图
- 用户已有领域地图 → 从深挖开始
- 学习产出需沉淀 → 走 harvest 交接 Fabric（不承担开启新项目的职能）

## Gotchas

- 未确认领域/深度/边界就建图 → 先确认三要素；模糊时用 `grilling`
- 跳过 `verify` 直接 `harvest` → 未验证结论不得写入收集箱
- 单一概念也建整张图 → 直接 `dig`，跳过建图
- 把学习产出直接放进领域 → 统一进收集箱，交接 Fabric 归位
