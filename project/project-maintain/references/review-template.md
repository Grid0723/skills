# 里程碑总结——提取流程

## 从 CHANGELOG 提取里程碑总结

### 输入：CHANGELOG 片段

```markdown
## v0.9.6 (2026-06-03)
### 新增
- 步骤导航引擎支持 Left 键回退上一步
### 修复
- 交互模式下参数重复采集导致前后不一致
### 变更
- prompt_helpers 提取为独立模块
```

### 输出：里程碑总结

```markdown
### 2026-06-03 — v0.9.6 导航引擎完善

- 核心变更: 步骤导航引擎新增 Left 键回退能力——用户可在参数采集过程中回到上一步修改
- 关键决策: 将参数展示从业务逻辑中分离为独立 prompt_helpers 模块——降低 Controller 与 View 的耦合
- 所学经验: 交互式 CLI 的"后退"功能需要保存 StepContext 快照而非仅依赖当前步——否则回退后无法恢复已填参数
```

## 提取三步法

### 1. 核心变更 — "完成了什么"
从 CHANGELOG 的"新增/修复"中提取**改变了用户体验或系统能力**的条目。跳过"更新依赖"、"代码格式"等纯维护条目。

### 2. 关键决策 — "做了什么重要选择及其原因"
从 CHANGELOG 的"变更/重构"和 ADR 中提取。问自己："如果重做这个功能，还会做同样的选择吗？"→ 如果是，这个选择值得记。

### 3. 所学经验 — "如果再来一次，知道了什么"
从 CHANGELOG 的"修复"中提取——每个 bug 修复背后都有"这一点我们之前没意识到"的教训。

  - ...
