# 捕获模板与场景示例

## 剪藏笔记模板

从网页 URL 捕获的笔记使用此模板：

```yaml
---
Author: 张谦
tags: [<主题领域标签>]
关键词: [<3-5个检索词>]
类型: 剪藏
来源: <微信/知乎/B站/小黑盒/其他>
source: <原始URL>
description: <一句话概括>
状态: 待整理
创建: <YYYY-MM-DD 周X HH:MM:SS>
修改: <YYYY-MM-DD 周X HH:MM:SS>
---

# <标题>

<原文内容>

---
## 原始元数据
- 作者: <原文作者>
- 发布时间: <原文发布时间>
- 原文链接: <URL>
```

## 速记笔记模板

灵感/碎片想法使用此模板：

```yaml
---
Author: 张谦
tags: [<临时标签>]
类型: 速记
description: <一句话记录想法>
状态: 待整理
创建: <YYYY-MM-DD 周X HH:MM:SS>
修改: <YYYY-MM-DD 周X HH:MM:SS>
---

# <日期 灵感主题>

<碎片内容>
```

## 捕获场景

### 场景 1：用户发送 URL

```
用户: 帮我保存这篇 https://zhuanlan.zhihu.com/p/xxx
AI:   （用 defuddle 或 WebFetch 提取正文）
      → 判断来源：知乎
      → 创建笔记：00_收集箱/剪藏/<文章标题>.md
      → frontmatter：类型=剪藏、来源=知乎、状态=待整理
      → 打初步标签：从文章内容判断主题领域
```

### 场景 2：用户口述灵感

```
用户: 刚才想到一个交易策略想法——用布林带宽压缩来预判突破方向
AI:   已在 00_收集箱/ 创建速记：类型=速记、状态=待整理
      → 内容记录你的原话 + 补充可能的标签：交易/策略
      → 不展开分析（捕获不加判断）
```

### 场景 3：微信读书笔记

```
用户: 帮我把这道微信读书笔记保存
AI:   → 类型=剪藏、来源=微信读书
      → 保留 doc_type/bookId/cover 等微信读书专属元数据
      → 内容保留原始格式和高亮
```
