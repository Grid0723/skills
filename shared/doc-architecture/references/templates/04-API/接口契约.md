# 接口契约

## 接口列表

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/xxx | … | 否/是 |

## 公共约定

- 基础路径: `http://localhost:<port>/api`
- 认证方式: Bearer Token / 无
- 金额字段: string 类型
- 分页参数: `?page=1&size=20`
- 错误响应格式: `{ "code": 400, "message": "…" }`

## 接口详情

### GET /api/xxx

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|

**响应**

```json
{
  "data": [],
  "total": 0
}
```

**错误码**

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 500 | 服务器错误 |
