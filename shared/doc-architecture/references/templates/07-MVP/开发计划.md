## 规则

- 阶段号整数、只增不减（禁止 `S1.5`、`R1`）
- 功能与 PRD 一一对应（`F2` ↔ `PRD-F02-*.md`）
- 一个功能一个分支：`feature/<项目码>-S<n>-F<n>`
- 每个 Task 1–2 小时内可完成、可独立演示
- 完成一个 Task 即标记 `[x]` 并提交一个 commit
