# 逐段塑形——改造全过程

## 完整示例：从 beat 到成品段落

### 输入：一条 beat

> **Beat 3: 布林带——把两个基础工具包在一起**
> 前置知识: 移动平均线 ✓、标准差 ✓
> 内容: 布林带由三条线组成——中轨是移动平均线，上下轨分别是加减 N 倍标准差。它把"趋势"和"波动率"这两种信息包在同一个视觉框架里。

### 输出：塑形后的三段式段落

```markdown
布林带之所以成为技术分析中少有的"一眼就能用"的工具，是因为它把两个原本独立的信息源——趋势和波动率——巧妙地包进了同一个视觉框架里。

**中轨 = 移动平均线**，告诉你"价格的大方向"。
**上下轨 = 中轨 ± N 倍标准差**，告诉你"正常的波动范围"。

当价格触及上轨，它既有方向（趋势向上）又有位置（在高波动区）。这种双维度信息让布林带比单独的均线或单独的波动率指标更不容易给出假信号。
```

### 改造要点

| 原 beat | 塑形后 | 改动 |
|---------|--------|------|
| "三条线组成" | 拆为"中轨"和"上下轨"两行加粗定义 | 拆复杂概念为可扫读 |
| 纯信息 | 加了"一眼就能用"的评价 | 给读者态度 |
| 无衔接 | "当价格触及上轨..." 将前文的中轨+波动组合起来 | 衔接桥：概念定义→实际意义 |

## 衔接桥的 3 种模式

### 1. 转折——从"旧认知"到"新视角"

```
上一段: 大多数交易者只看价格本身。
衔接桥: ==但布林带告诉你，价格的位置比价格本身更重要==——同样的上涨，在上轨附近和在中轨附近，含义完全不同。

下一段: 上轨突破往往是趋势加速的信号...
```

### 2. 递进——从"是什么"到"怎么用"

```
上一段: 布林带由中轨（均线）和上下轨（均线±N倍标准差）组成。
衔接桥: ==理解这三条线的含义只是第一步。==真正的价值在于观察它们之间的相对位置变化。

下一段: 当布林带宽度收缩到近期最小值时...
```

### 3. 举例——从"抽象概念"到"具体场景"

```
上一段: 布林带宽度压缩预示着即将出现较大的方向性突破。
衔接桥: ==举个具体的例子。==2024 年 3 月，某 ETF 的布林带宽度在持续 20 个交易日收窄后突然扩张...

下一段: 那一次突破的方向是向上，原因是...
```

## 常见塑形错误

| 错误 | 表现 | 修复 |
|------|------|------|
| beat 内容丢失 | 塑形时加入了修辞但删掉了原始 beat 中的核心信息 | 对照 beat 清单——每一条核心信息必须在段落中 |
| 衔接桥过度解释 | "上段讲了 A，接下来我们看 B，B 是 A 的延伸..." | 衔接桥是**桥**不是**解说员**——直接走上去 |
| 跳过 Grounding 验证 | 段落中引入了一个 beat 未声明的概念 | 检查"已接地清单"——该概念的前置知识在前段是否已建立 |
| 每段"总结式收尾" | 每个段落都以"综上所述..."结尾 | 只在实际需要收尾时才总结——过度总结让文章节奏线性单调 |
