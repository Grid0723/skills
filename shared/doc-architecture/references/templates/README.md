# 项目文档索引

`docs/` 目录为本项目的设计基准，按"文档驱动开发"原则组织。

## 文档结构

```bash
docs/
├── README.md                     # 📖 本文档
├── CHANGELOG.md                  # 版本变更记录
│
├── 01-Requirements/              # 📋 需求文档
│   └── PRD-F<nn>-<功能名>.md     # 产品需求文档（含可选「功能域」小节）
│
├── 02-Architecture/              # 🏗️ 架构文档
│   ├── 系统架构.md               # 固定入口：模块 + 技术栈 + 数据流
│   ├── 开发指南.md               # 开发流程与规范
│   └── design/                   # 按需：专题设计（技术架构、信息架构、时序图）
│
├── 03-Database/                  # 🗄️ 数据库设计
│   ├── 数据库设计.md             # ER 图 + 表结构
│   └── 数据字典.md               # 字段级说明
│
├── 04-API/                       # 🔌 API 契约
│   └── 接口契约.md               # 接口定义
│
├── 05-ADR/                       # 📝 架构决策记录
│   └── ADR-<nnn>-<中文短名>.md   # 决策记录（模板见 0000-ADR模板.md）
│
├── 06-DevOps/                    # 🚀 运维部署
│   ├── 部署指南.md               # 环境搭建
│   └── 故障排查.md               # FAQ
│
├── 07-MVP/                       # 🎯 实施
│   ├── 实施概览.md               # 目标 + 功能清单
│   ├── 实现日志.md               # 里程碑记录
│   ├── 开发计划.md               # 唯一任务源：S → F → T
│   └── 计划/                     # 可选：单阶段任务 >10 个时拆
│
├── 08-Testing/                   # 🧪 测试
│   ├── 测试手册.md               # 测试用例
│   ├── 测试记录.md               # 执行记录
│   └── S<n>-验收清单.md          # 阶段验收
│
└── 09-参考资料/                   # 📚 外部资料、社区、竞品
```

> 架构图怎么画见项目所用 `doc-architecture` skill 的 `references/架构视图指南.md`——默认只画系统架构与数据流两张，其余按条件触发。
