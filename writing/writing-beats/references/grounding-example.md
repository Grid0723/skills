# Grounding 接地示例

## 概念依赖推导

假设碎片堆中包含这些概念：
- 布林带宽度压缩
- 布林带（Bollinger Bands）
- 标准差
- 移动平均线
- 双向条件单
- 波动率

### 依赖分析

```
波动率 → 不需要前置知识（直觉概念）
  ↓
布林带 → 依赖：移动平均线 + 标准差
  ↓
布林带宽度压缩 → 依赖：布林带
  ↓
双向条件单 → 不依赖其他概念（交易常识）
```

### Beat 序列编排

```
Beat 1: 波动率——市场的"心跳"（Ground: 零前置）
Beat 2: 移动平均线 + 标准差（Ground: 零前置，数学基础）
Beat 3: 布林带——把两个基础工具包在一起（Ground: Beat 2 ✓）
Beat 4: 布林带宽度压缩——当带宽收缩到极值（Ground: Beat 3 ✓）
Beat 5: 双向条件单——如何捕捉突破（Ground: 零前置，新分支）
Beat 6: 把 Beat 4 和 Beat 5 结合——完整策略（Ground: Beat 4 ✓ + Beat 5 ✓）
```

"已接地清单"随编排推进而增长：每个 Beat 在入选前检查其依赖是否全在其中。
