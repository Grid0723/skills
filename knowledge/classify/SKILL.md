# classify

判断一篇笔记归属于哪个领域或项目。

## Leading Words

| 术语 | 定义 |
|------|------|
| **文件夹定位置，标签管主题** | 物理上只放一个文件夹（主体领域），跨领域用标签桥接 |
| **待归类 = 人工判断等待** | 无法自动判断归属的笔记，标记后等待用户决策 |

## 步骤

### 1. 读取笔记内容

读取笔记全文和已有 frontmatter。

- 完成标准：理解笔记的核心主题

### 2. 对照 9 领域表

| 领域 | 典型内容 |
|------|---------|
| 交易投资 | 量化策略、K线分析、金融数据 |
| 编程技术 | Python、Node.js、TypeScript、算法 |
| 数据科学统计 | Pandas、Polars、数据可视化 |
| 音乐制作 | — |
| 家居家装 | — |
| DIY | — |
| 家庭网络与服务器 | NAS、Docker、服务器运维 |
| 思想阅读 | 书籍笔记、方法论、认知 |
| 工具与效率 | 效率工具、自动化、Obsidian 技巧 |

- 如果笔记服务于活跃项目 → 归入 `20_项目/<项目>/`
- 如果跨领域 → 取主体领域放文件夹，补跨领域标签

- 完成标准：归属方向已确定

### 3. 向用户确认

> 这篇笔记建议归入 `10_领域/<领域>/`，主题标签 `#领域/子主题`。是否确认？

- 不确定 → 标为 `00_收集箱/待归类/`，`状态: 待整理`
- 用户确认 → 进入归位阶段

- 完成标准：归属已确认或标为待归类的
