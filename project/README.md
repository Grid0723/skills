# project

项目管理原子技能组——挂靠 Fabric 编排器，独立于知识管理阶段管道。用户调用。

- **[project-init](./project-init/SKILL.md)** — 创建新项目：**总览文档+外部链接，`项目阶段: 启动`**。阶段流转：启动→进行中→暂停→收尾→完成→归档。
- **[project-plan](./project-plan/SKILL.md)** — 按功能模块分组任务：**`- [ ] 任务 #项目/<名>`**。每个模块独立可验证，可在任意笔记执行。
- **[project-review](./project-review/SKILL.md)** — 里程碑回顾：**CHANGELOG/commit log →「📝 里程碑总结」**。提取核心变更、关键决策、所学经验。
- **[project-links](./project-links/SKILL.md)** — 维护外部链接：**`file:///` 本地路径和外部 URL**，统一聚合于 `20_项目/外部链接.md`。
- **[project-archive](./project-archive/SKILL.md)** — 项目收尾：**先反哺知识到 `10_领域`→ 再移入 `90_归档`**。先提炼再归档。
